covered by this repository's MIT licence. It is included only so that UCL
staff and students can produce posters that follow the UCL template. Use it
under UCL's brand guidelines:
<https://www.ucl.ac.uk/brand-and-experience/brand/visual-guidelines/logo>

If you would like to use the logo outside of this template, you must request this via the form available in:
<https://www.ucl.ac.uk/brand-and-experience/brand/contact-us>
